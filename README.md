# ☕ Exercícios de Java

Repositório destinado ao armazenamento dos exercícios e atividades desenvolvidos durante meus estudos de **Java**.

## 🎯 Objetivo

Este repositório tem como objetivo registrar minha evolução no aprendizado da linguagem Java, reunindo exercícios práticos e exemplos desenvolvidos durante as aulas e estudos.

## 💻 Conteúdos estudados

Durante os exercícios, são abordados conceitos como:

* Variáveis e tipos de dados
* Entrada e saída de dados
* Operadores
* Estruturas condicionais (`if`, `else`, `switch`)
* Estruturas de repetição (`for`, `while`, `do while`)
* Métodos
* Arrays
* Strings
* Listas e coleções
* Classes e objetos
* Construtores
* Encapsulamento
* Herança
* Polimorfismo
* Orientação a Objetos
* Tratamento de exceções
* Outros conceitos da linguagem Java

## 📂 Organização

Os exercícios estão organizados em pastas de acordo com as aulas, temas ou atividades.

Exemplo:

```text
Exercicios-Java/
│
├── ExerciciosGitJAVA/
│   ├── CodigosTps/
│   ├── CodigosTps1/
│   ├── CodigosTps2/
│   └── ...
│
└── README.md
```

## 🛠️ Tecnologias utilizadas
